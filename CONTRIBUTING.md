# Contributing

This repository is maintained by TrustPin and is not open source. We do not accept pull requests.

Found a mistake, an outdated instruction, or a case where an agent did the wrong thing? Open an issue, or email contact@trustpin.cloud. For technical help with TrustPin itself, write to support@trustpin.cloud. Say which agent and version you used, which SDK version, and what the agent did compared with what you expected. Do not paste secrets.

By sending us feedback you allow TrustPin to use it freely, without obligation to you.

Security problems: see [SECURITY.md](SECURITY.md).
