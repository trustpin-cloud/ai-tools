# Security

To report a vulnerability in anything in this repository (the skill text, the bundled script, or the release workflow), or a security issue in TrustPin itself, email contact@trustpin.cloud with "Security" in the subject. Please do not open a public issue.

Include what you found, where, and how to reproduce it. Do not include secrets, API tokens, master passwords, or private keys.

Please give us a reasonable time to respond and fix the problem before disclosing it publicly.
